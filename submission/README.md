# DeepGen complete handoff

[Download the complete project ZIP and individual artifacts](https://github.com/Ayush20990/ie643-project/releases/tag/intensive-assessment-2026-10-20).

The release contains the application, saved source/adapted models, datasets, results,
plots, reports, presentation, study guide and offline dashboard. Extract the entire
ZIP before running `START_APP.py`; its README explains dependencies and verification.

The source repository contains the project assets directly. Temporary previews,
Python/Node environments and duplicate generated package folders stay local.
Generate a fresh package from a clone with `python -m src.package_submission`.

The technical files and GitHub handoff are complete. Both team members should still
review the report in their own words, record the required code walkthrough/demo,
verify TA dataset approval and complete the course submission process. The detailed
recording guide is inside the packaged ZIP. Uploading to GitHub does not submit to
the course or deploy the Streamlit app publicly.
