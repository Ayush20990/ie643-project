LiteTCN follow-up: unfreezing and predicted-driver correction

Supporting model evidence · 19 October 2026 · not the final assessment report. All old checkpoints are preserved.

Measured conclusion

The final composition yields a small energy improvement over retained LiteTCN-R: 0.146226 → 0.146098 multivariate MSE and 4.09915 → 4.08351 degC temperature RMSE. Each of the three energy training seeds improves slightly. Climate is effectively unchanged/slightly worse: 0.220609 → 0.220615 MSE, 1.32844 → 1.32935 degC. These results do not establish a meaningful peak fix or a new best model. The previous hybrid/DLinear alternatives remain stronger overall; the existing strict ensemble remains stronger for energy temperature RMSE. Training-seed consistency is not statistical significance over independent time periods.

What was tested

  1. Gradual LiteTCN-R encoder unfreezing: matched head-only control, three seeds, 24 sampled rounds. Source validation rejects late unfreezing checkpoints. Input adaptation gives limited/mixed development results; see the separate gradual-unfreezing notes.
  2. Source-only driver analysis: compare temperature/calendar forecasts with and without past load or weather summaries. No target data or true future driver inputs. These are predictive-association diagnostics, not causal claims.
  3. Small decoder on frozen source LiteTCNs: compare temperature-only vs driver-conditioned residuals using the same multivariate base and decoder size. The temperature-only ablation removes extra non-temperature decoder conditioning; the base itself is still multivariate. Source validation selects coupled conditioning for climate, temperature-only for energy. Source-validation gains do not reliably transfer.
  4. Compose the decoder with the retained input-adapted LiteTCN. This avoids comparing a source-only backbone with a fully adapted earlier model. Include exact zero correction, source decoder and input-adapted decoder candidates; preserve the backbone weights and every non-temperature forecast exactly.

Architecture and optimization

The base forecasts all channels: LiteTCN v3 for climate, LiteTCN-R for energy. The new temperature head has 2,689 parameters, two 32-unit GELU layers and a zero-initialized scalar output. Inputs at each future step are the base's predicted variables, their changes relative to the last observation, observed-window means/log standard deviations/last normalized levels/recent means, deterministic future calendar features, and relative horizon. All normalization statistics use the observed input only. Multiply the head output by the observed temperature standard deviation and add it only to the temperature forecast. No observed future load, cloud, humidity or radiation values are supplied.

Decoder source controls use AdamW 0.0005, weight decay 0.001, cosine decay, 16 sampled rounds of at most 4,096 windows, batch 256. Objective and source selection use 0.5 global standardized MSE + 0.5 temperature MSE, with a 3% source-MSE guard and zero-correction fallback. Adaptation of the source-backbone decoder uses six rounds at 0.0001, source replay and relative-layer anchor 0.01. Final composition uses eight rounds at 0.0001, the same replay/anchor, and both zero/source-head initial candidates. Models are fitted for seeds 0, 1 and 2 on CPU.

Target adaptation withholds the final 24 observed values inside each individual input. Prefix padding never contains the withheld suffix. All decoder features are built from that prefix and the frozen backbone's forecasts. Target forecasting Y tensors and reconstructed labels from neighboring windows are excluded. Final composition selection is 0.5 relative source-validation objective + 0.5 relative target-input objective, with a source-MSE guard of 10% relative to the zero-correction backbone. Cached historical training-period scalers remain unchanged for comparison. All dataset/seed choices are frozen before test inference.

Development tests have already been inspected in earlier work. The 1–17 October weather check was frozen before download for the gradual-unfreezing model, but was already inspected before these decoder experiments. It is not claimed as independent confirmation for either decoder model; no decoder result is selected using that period. No independent new energy period is available.
