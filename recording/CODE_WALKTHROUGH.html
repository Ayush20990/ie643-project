 43  def chrono_split(arrays, split, L):
 44      """Chronological split per series. val/test segments are prefixed with L steps of context."""
 45      out = {"train": [], "val": [], "test": []}
 46      for x in arrays:
 47          n = len(x)
 48          a, b = int(n * split[0]), int(n * (split[0] + split[1]))
 49          out["train"].append(x[:a])
 50          out["val"].append(x[a - L:b])
 51          out["test"].append(x[b - L:])
 52      return out

 55  def make_windows(arrays, L, H, stride=1):
 56      xs, ys = [], []
 57      for x in arrays:
 58          if len(x) < L + H:
 59              continue
 60          w = np.lib.stride_tricks.sliding_window_view(x, L + H, axis=0)[::stride]  # (N, C, L+H)
 61          w = np.ascontiguousarray(w.transpose(0, 2, 1))
 62          xs.append(w[:, :L])
 63          ys.append(w[:, L:])
 64      return torch.from_numpy(np.concatenate(xs)), torch.from_numpy(np.concatenate(ys))

Event loss, observed episodes and source safeguards

Do on screen
  1. Show collect_episodes in src/peak_nowcast_train.py. Its arguments contain input_windows, not target Y.
  2. Point at EVENT_WEIGHT / RAMP_WEIGHT, then objective and constraints inside fit_weights.
  3. Keep the matrix algebra collapsed; explain its purpose only.
This collector creates a daily episode of successive one-hour practice forecasts entirely inside an already observed input. At each practice origin only the earlier prefix is visible. The event objective combines point MSE, twice the peak-and-trough error, and 0.1 times ramp error. Historical extrema identify the calibration loss locations, but never enter the regime features. This separates event supervision during fitting from causal inputs during prediction. The final calibration fits mixture weights with constrained SLSQP, rather than retraining all neural experts.
